🏃CodeRunner Game

📌 Project Overview

CodeRunner Game is an interactive educational programming game developed to help students learn and practice Python programming through a level-based gaming environment.

Players collect Python code fragments, avoid bugs and errors, and solve coding challenges by reconstructing and executing the collected code. The system checks the output and tracks the player's score and progress.

---

📦 Modules Included

- User Registration & Login
- Home Page
- Level Selection
- Interactive Game Module
- Python Code Collection
- Coding Challenge Module
- Python Code Execution
- Score & XP Management
- Player Profile
- Leaderboard
- MongoDB Database Management

---

🌟 Benefits

- Makes Python learning interactive and engaging
- Improves programming and problem-solving skills
- Provides practical coding and debugging experience
- Allows users to execute and test Python programs
- Tracks player scores, XP, levels, and progress
- Encourages learning through game-based challenges

---

🛠️ Tech Stack

- Frontend: HTML, CSS, JavaScript, ASP.NET Web Forms
- Programming Language: VB.NET, Python
- Backend: Node.js, Express.js
- Database: MongoDB
- Web Service: ASP.NET Web Service (ASMX)
- Development Tools: Visual Studio 2010, Visual Studio Code

---

🔄 Project Flow

Login → Home → Level Selection → Game → Collect Code → Coding Challenge → Execute Python Code → Compare Output → Update Score → Next Level
